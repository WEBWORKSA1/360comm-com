# 360Comm.com — The 360° Business Communications Hub

A site for comparing business phone/VoIP, contact center, video, team chat, business SMS and business internet providers. It includes independent comparisons, free calculators, guides, videos and a no-obligation quote marketplace. It is built natively for the **free GitHub Pages plan**: plain HTML, CSS and JS, assembled by GitHub's built-in Jekyll. There is no build step and no Actions workflow.

- **Live:** https://webworksa1.github.io/360comm-com/ (after Pages is enabled; see below)
- **Strategy and phase-wise build prompt:** [BUILD-PROMPT.md](BUILD-PROMPT.md)

## Structure
```
_config.yml                     Jekyll settings
_layouts/default.html           <head>, header, footer (shared by every page)
_layouts/provider.html          data-driven provider review template
_includes/                      header, footer, quote card, comparison rows
index.html  quotes.html (6-step lead wizard)  compare.html  head-to-head.html
providers/ (15)  categories/ (6)  tools/ (7 calculators)  guides/ (8)
videos, glossary, donate, contests, careers, advertise, partners, contact
about, methodology, disclosure, privacy, terms, legal (trademark/copyright), 404
sitemap.html / sitemap.xml / search-index.json   generated by Liquid
assets/css/style.css  assets/js/main.js  assets/js/tools.js
src/data.py                     master content data (reference)
```

## Enable hosting (one time, about 30 seconds)
Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `(root)` → Save**. The site goes live at `https://webworksa1.github.io/360comm-com/` within a minute or two.

## Configuration (`assets/js/main.js` → `CONFIG`)
| Key | Purpose |
|---|---|
| `FORM_ALIAS` | Optional FormSubmit alias. The single inbox address is stored obfuscated in JS and never appears in the HTML. |
| `ADSENSE_CLIENT` | `ca-pub-…` ID. Once set, every `.ad-slot` becomes a responsive AdSense unit; until then the slots show house ads that sell advertising. |
| `DONATE.kofi / bmc / github` | Donation platform URLs. Empty ones are hidden automatically. PayPal is built from the hidden address. |

**First form submission:** FormSubmit sends a one-time activation email to the inbox. Click it to start receiving submissions.

## Adding a provider
Copy any `providers/*.html` file, edit its front matter, and add a matching `_includes/row-<slug>.html` row for the comparison tables.

## Custom domain (360comm.com)
1. Add a file named `CNAME` containing `360comm.com`.
2. At the DNS provider, add A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`, plus `www` CNAME → `webworksa1.github.io`.
3. Go to Settings → Pages → Custom domain and turn on Enforce HTTPS.
4. Find and replace `https://webworksa1.github.io/360comm-com` with `https://360comm.com` in the page front matter, `robots.txt` and the layout. In `404.html`, set `root: "/"`.
